# Rick and Morty — каталог персонажей

Flutter-приложение для просмотра и поиска персонажей с использованием [Rick and Morty API](https://rickandmortyapi.com/documentation). Проект основан на [base_flutter_proj](https://github.com/5tepan/base_flutter_proj).

## Возможности

- Каталог с изображением, именем и статусом персонажа, постраничная загрузка при прокрутке.
- Поиск по имени и очистка запроса.
- Детальная информация о персонаже; после возврата сохраняются поиск, загруженные данные и позиция списка.
- Состояния загрузки, ошибки с повторной попыткой и отсутствия результатов.

## Запуск

Требуются Flutter SDK с Dart 3.12 или новее и подключение к интернету. Проект проверен на Flutter 3.47.6 / Dart 3.13.5.

```bash
flutter pub get
make setup-secrets
make run-dev
```

`make setup-secrets` создаёт локальные файлы конфигурации из примеров, не перезаписывая существующие. Для веба после подготовки можно запустить `make run-web-dev`. По умолчанию все конфигурации используют публичный API `https://rickandmortyapi.com/api/`; ключ API и авторизация не требуются.

## Устройство

Фича находится в `lib/characters/`: модели, API, репозиторий, Riverpod-провайдеры, маршруты, экраны и их компоненты. Общие сетевые и UI-компоненты расположены в `lib/core/`. Навигация построена на go_router, локализация поддерживает русский и английский языки.

После изменения моделей или маршрутов выполните `make generate`, после изменения ARB-файлов — `make intl`.
