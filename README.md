# Rick and Morty — каталог персонажей

Подготовленный Flutter-проект на основе [base_flutter_proj](https://github.com/5tepan/base_flutter_proj).

В проекте сохранены инфраструктура и соглашения базового приложения: Riverpod, go_router, сетевой слой на Dio, локализация, тема и компоненты пагинации.

## Запуск

```bash
flutter pub get
make setup-secrets
make run-dev
```

API будущего каталога: [Rick and Morty API](https://rickandmortyapi.com/documentation).
